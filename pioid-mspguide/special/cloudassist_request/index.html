    PIO-IDクラウドアシスト

    本ガイドの対象

    PIO-IDの特権MSPアカウントをお持ちの販売店様を対象としています。

    PIO-IDクラウドアシストとは

    PIO-IDクラウドアシストは、販売店様が無償で利用できるサポートアカウント機能です。

    顧客用のPIO-ID 管理者ポータルで、ログインし直すことなく顧客アカウントを切り替えて、各顧客の管理画面へアクセスできます。顧客の契約内容や設定を確認し、マネージドサービスの対応を効率化するために利用します。

    提供条件

    PIO-IDクラウドアシストの無償提供条件は、1年間に1件以上の新規顧客アカウント契約があることです。契約ユーザ数は問いません。

    条件未達時の扱い

    1年間に1件も新規顧客アカウント契約がない場合は、以下のいずれかを選択します。

    選択肢 扱い
    一時停止 最長1年間、PIO-IDクラウドアシストを利用できない状態にします。サポートアカウントは解約しません。
    解約 サポートアカウントを解約します。解約後は、PIO-IDクラウドアシストを再度申し込むことはできません。
    有償で継続 無償提供を終了し、有償のサポートアカウントとして継続します。

    一時停止は、サポートアカウントの即時解約ではありません。サポートアカウントに登録されている販売店管理者を削除し、クラウドアシストへログインできない状態にしたうえで、1年後の解約予定日を設定する運用です。

    Info

    一時停止期間は最長1年間です。一時停止期間中に新規顧客アカウント契約が発生した場合は、クラウドアシストの利用を再開できます。一時停止から1年経過しても条件を満たさない場合は、サポートアカウントを解約します。

    Warning

    解約された場合、同じ販売店様がPIO-IDクラウドアシストを再度申し込むことはできません。サポートアカウントが必要な場合は、有償のサポートアカウントをご利用ください。

    クラウドアシストの申請手順

    1. MSP用のPIO-ID 管理者ポータル＞管理アカウント＞MSPアカウント一覧画面へ移動します。
    2. 登録ボタンをクリックします。登録画面が表示されます。

    3. 以下の内容を入力し、登録ボタンをクリックします。

      設定項目 設定内容
      アカウントタイプ サポートアカウントを選択します。
      ウェブサイト 販売店のホームページURLを入力します。
      会社名 販売店の正式名称を入力します。
      電話番号 販売店の電話番号を入力します。
      住所 販売店の所在地を入力します。
      契約ユーザ数 0を設定します。0を設定できない場合は、設定可能な最小値を入力します。

    Warning

    クラウドアシストの申請が完了しても、PIO-IDによる承認およびプロビジョニングが完了するまで、顧客アカウントとの紐づけや管理者登録は行えません。

    利用開始手順

    PIO-IDからプロビジョニング完了の連絡を受けた後、以下の作業を行います。

    顧客アカウントとの紐づけ

    1. MSP用のPIO-ID 管理者ポータル＞管理アカウント＞顧客アカウント一覧画面へ移動します。
    2. クラウドアシストで対応する顧客アカウントの編集ボタンをクリックします。
    3. サポートタブへ移動します。
    4. サポートアカウントで、該当するサポートアカウントを選択します。
    5. 更新ボタンをクリックします。

    サポートアカウントへの管理者登録

    1. PIO-ID 管理者ポータルへ移動します。
    2. 画面上部の顧客切り替えから、該当するサポートアカウントを選択します。
    3. 管理＞管理者画面へ移動します。
    4. 販売店の管理者を登録します。

    Info

    管理者を登録すると、登録したメールアドレス宛に管理者の登録通知が送信されます。パスワード設定で設定URLメール送信を選択した場合は、パスワード設定の案内も送信されます。

    年次見直し

    PIO-IDクラウドアシストの利用状況は、年1回見直します。

    確認する内容は以下です。

    • 対象販売店の直近1年間の新規顧客アカウント契約数
    • 条件未達の場合の対応方針（一時停止、解約、有償で継続）
    • 有償サポートアカウントへの切り替え希望

    一時停止手順

    条件未達によりPIO-IDクラウドアシストを一時停止する場合は、以下を行います。一時停止期間は最長1年間です。

    1. 対象販売店へ、クラウドアシストを一時停止する旨を連絡します。
    2. MSP用のPIO-ID 管理者ポータル＞管理アカウント＞MSPアカウント一覧画面へ移動します。
    3. 対象のサポートアカウントの編集ボタンをクリックします。
    4. 会社名の先頭に 一時停止中 を追記し、更新ボタンをクリックします。
    5. 対象のサポートアカウントの解約予定日列の設定ボタンをクリックします。
    6. 解約予定日に、一時停止日から1年後の日付を設定します。
    7. PIO-ID 管理者ポータルへ移動します。
    8. 画面上部の顧客切り替えから、対象のサポートアカウントを選択します。
    9. 管理＞管理者画面へ移動します。
    10. 販売店の管理者を削除します。

    Info

    会社名が 株式会社サンプル販売 の場合は、一時停止中 株式会社サンプル販売 のように変更します。

    Warning

    一時停止では、サポートアカウントを即時解約しないでください。サポートアカウント自体や顧客アカウントとの紐づけは残し、1年後の解約予定日を設定したうえで、サポートアカウントへログインできる管理者を削除します。

    Danger

    削除された管理者は復元できません。利用再開時には、サポートアカウントへ管理者を再登録してください。

    一時停止後の確認

    一時停止後、以下を確認します。

    • 対象サポートアカウントの管理者が削除されていること
    • 対象サポートアカウントが解約されていないこと
    • 対象サポートアカウントの会社名の先頭に 一時停止中 が追記されていること
    • 対象サポートアカウントに、一時停止日から1年後の解約予定日が設定されていること
    • 対象サポートアカウントと顧客アカウントの紐づけが維持されていること

    利用再開手順

    一時停止期間中に新規顧客アカウント契約が発生した場合は、クラウドアシストの利用を再開できます。

    利用を再開する場合は、以下を行います。

    1. 対象サポートアカウントの会社名の先頭から 一時停止中 を削除します。
    2. 対象サポートアカウントの解約予定日を解除します。
    3. サポートアカウントへの管理者登録の手順に従い、サポートアカウントへ販売店の管理者を再登録します。

    解約手順

    条件未達時に解約を選択した場合、または一時停止から1年経過しても条件を満たさない場合は、サポートアカウントを解約します。

    解約処理は、MSPアカウント管理の解約処理を参照してください。

    Warning

    解約後は、PIO-IDクラウドアシストを再度申し込むことはできません。今後サポートアカウントが必要な場合は、有償のサポートアカウントをご利用ください。

    有償で継続する場合

    条件未達後も継続して利用する場合は、有償のサポートアカウントとして継続します。詳細は、担当営業へご相談ください。
